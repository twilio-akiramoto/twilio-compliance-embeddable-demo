# Debug Steps for Error 400

Please check the following in your browser:

## 1. Open Browser Developer Tools
- **Chrome/Edge**: Press F12 or Cmd+Option+I (Mac) or Ctrl+Shift+I (Windows)
- **Firefox**: Press F12 or Cmd+Option+I (Mac) or Ctrl+Shift+I (Windows)

## 2. Check the Console Tab
Look for any error messages (usually in red). Please share:
- The full error message
- Any stack traces

## 3. Check the Network Tab
1. Keep Developer Tools open
2. Click "Initialize Inquiry" again
3. Look for failed requests (shown in red)
4. Find any request with status 400
5. Click on it and share:
   - Request URL
   - Request Headers
   - Response body

## 4. Check iframe errors
Look for errors related to:
- `withpersona.com` 
- `persona-verify`
- CORS errors
- Security/CSP errors

Please share what you see!
